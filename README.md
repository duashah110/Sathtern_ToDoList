# Sathtern To-Do List

A responsive To-Do List application built using HTML, CSS, and JavaScript as part of the **Sathtern Web Development Virtual Internship**.

The application allows users to add, edit, delete, complete, and filter tasks. Tasks are stored using browser Local Storage, so they remain available even after refreshing the page.

## 🌐 Live Demo

https://duashah110.github.io/Sathtern_ToDoList/

## 📌 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by:
  - All
  - Active
  - Completed
- Clear completed tasks
- Task counter
- Local Storage support
- Enter key support for adding tasks
- Responsive design
- Mobile-friendly interface

## 🛠️ Technologies Used

## ⚙️ How It Works

1. The user enters a task in the input field.
2. JavaScript creates a task object.
3. The task is displayed in the task list.
4. Tasks are saved in the browser using Local Storage.
5. Users can edit, delete, or mark tasks as completed.
6. The filter buttons allow users to view All, Active, or Completed tasks.
7. Saved tasks remain available after refreshing the page.

## 💾 Local Storage

The application uses the browser's **Local Storage** to save tasks locally.

This allows tasks to remain available even after the page is refreshed.

## 📱 Responsive Design

The application is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile devices

CSS media queries are used to adjust the layout for smaller screens.
